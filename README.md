# 🗑️ Voldena Uninstaller

[🇹🇷 Türkçe sürüm](Beni%20Oku.md)

A modern and fast Windows desktop uninstaller utility that helps fully uninstall applications and clean up leftover files and registry keys.

## ✨ Features

- 🧹 **Deep Clean**: Scans and removes residual program files and registry entries.
- 🎨 **Modern UI**: Clean and minimal user interface for listing and managing installed apps.
- ⚡ **Fast & Lightweight**: Built with Electron for high performance.
