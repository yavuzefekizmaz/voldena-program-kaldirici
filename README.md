# 🗑️ Voldena Program Kaldırıcı

[🇺🇸 English version](README.en.md)

Uygulamaları sisteminizden tamamen kaldırmak, kayıt defteri kalıntılarını ve artık dosyaları derinlemesine temizlemek için tasarlanmış modern ve hızlı bir Windows program kaldırıcı aracı.

## ✨ Özellikler

- 🧹 **Derinlemesine Temizlik**: Programların geride bıraktığı artık dosyaları ve kayıt defteri (registry) girdilerini tarayıp siler.
- 🎨 **Modern Arayüz**: Kurulu uygulamaları listelemek ve yönetmek için temiz, minimalist tasarım.
- ⚡ **Hızlı ve Hafif**: Yüksek performans için Electron ile geliştirilmiştir.
